# Minecraft Real Passport Mod

一个适用于 Minecraft Fabric 1.21.1 的护照系统模组。

## 📖 简介 (About)
这个模组为服务器或单人游戏增加了一套真实的护照/身份验证系统。玩家可以注册、签发护照，并在游玩过程中使用。*(请根据你实际的Mod功能修改这段话)*

## 🛠️ 前置需求 (Requirements)
- Minecraft 1.21.1
- Fabric Loader (>= 0.15.11)
- Fabric API (必须安装)

## 📥 安装方法 (Installation)
1. 确保你已经安装了 Fabric Loader。
2. 下载本模组对应的 `.jar` 文件。
3. 将 `.jar` 文件放入 Minecraft 游戏目录下的 `mods` 文件夹中。
4. 重启游戏。
